# Ofan for Visual Studio Code

[![CI](https://github.com/ofan-lang/VSCode/actions/workflows/ci.yml/badge.svg)](https://github.com/ofan-lang/VSCode/actions/workflows/ci.yml)

VS Code language support for [Ofan](https://github.com/ofan-lang/Ofan) — a
systems programming language with compile-time memory safety and a low learning
curve.

## Features

- Syntax highlighting for `.ofan` files
- Editor configuration (indentation, bracket matching, comment toggling)

## Requirements

VS Code 1.95.0 or later.

## Extension settings

This extension contributes no settings.
